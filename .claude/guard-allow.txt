# Исключения из запретов хуков. Одна регулярка на строку, регистр не важен.
# Строка, совпавшая с командой или путём, снимает блокировку — пользоваться
# осознанно и по одной, а не «разрешить всё».
#
# Пример: разрешить работу с шаблоном окружения
# \.env\.example$

# Создание рабочих веток по соглашению проекта — разрешено сэром явно
# («создавай МР, пушь»). Ветки вне соглашения по-прежнему требуют подтверждения.
git (?:checkout -b|switch -c) (?:feature|fix|chore|docs|test)/[a-z0-9._-]+$
git worktree add \.worktrees/[a-z0-9._-]+ -b (?:feature|fix|chore|docs|test)/[a-z0-9._-]+ (?:main|origin.main)$
git worktree remove \.worktrees/[a-z0-9._-]+$
