Запусти workflow `feature` для задачи ниже.

Задача: $ARGUMENTS

Вызов: `Workflow({ name: "feature", args: { task: "$ARGUMENTS" } })`

Эта команда — явное разрешение на многоагентную оркестрацию: вызывай Workflow
сразу, подтверждения не спрашивай. Перед запуском проверь `gh auth status`
и скажи сэру, если авторизации нет, — ступень MR без неё не пройдёт.

Когда workflow вернёт результат: покажи ветку, ссылку на PR и статус CI.
Если CI красный — назови упавшую проверку и причину, не объявляй работу законченной.
