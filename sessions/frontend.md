## Реализация (та же сессия, позже)

Ветка `feature/frontend-sandbox` — создана в дереве харнеса разрешённой
формой из guard-allow.txt, синхронизирована с main (worktree-путь из задачи
недостижим из-за расхождения корней unlock/guard-scope — принято проджектом,
заведено #35). Коммит `c9d2db8`: `frontend/` — React + Vite + TS.

Решения реализации, помимо генерации типов:

- **U2 «дословно»** — единица хранения последнего запроса: сырая строка тела
  плюс ключ; повтор шлёт её байт-в-байт без пересериализации (тест).
- **Клиентской валидации формы нет** — показать 422 сервера и есть работа
  песочницы; целая сумма уходит числом, нечисловая — строкой (422 «строка»).
- **Журнал data-driven**: семантика записи выводится из кода ответа
  (201/200/409/прочее/нет ответа), `error.code` берётся из тела — новые коды
  #32 (`malformed_request`, `invalid_idempotency_key`) отобразятся без правок.
- **GET списка в журнал не пишется** — журнал показывает обмены пользователя,
  как в макете (там только POST-записи); список обновляется после каждого
  create/cancel, чтобы «повторы список не увеличивают» было видно.
- **Сценарии самодостаточны**: свой ключ (crypto.randomUUID), своё тело;
  гонка — Promise.all из двух fetch, группа в журнале с общим чипом ключа,
  ожидание «201 + 409» (фиксация #32).
- **Пустое описание не отправляется** (поле не кладётся в тело) — строго
  четыре поля контракта, additionalProperties: false учтён.
- **Тело ответа** раскрывается кнопкой; для «тот же платёж» раскрыто сразу,
  `id`/`created_at` подсвечены токенами `--color-code-highlight*`.
- **tokens.css скопирован из design/ байт-в-байт**; композиция app.css
  перенесена из sandbox.html; брейкпоинт 1100 и литерал стрелки select —
  с оговорёнными комментариями. Шрифты — @fontsource, не CDN.
- **Docker**: multi-stage node:22-alpine → nginx:1.27-alpine, статика на 8081,
  `ARG VITE_API_BASE` вшивается на сборке.

Проверено: vitest 11/11 зелёные (A10-тест: `<script>` в description виден
текстом, узлов script/b в DOM нет; U2-тест байт-в-байт; деньги; семантика);
`npm run build` проходит; смоук UI headless-браузером на 1280 и 375 —
рендер по макету, C7 при недоступном API, пустые состояния, дизейбл повтора
до первого запроса, `scrollWidth == 375`. Бэкенд на 8080 ещё не поднят —
приёмочные скриншоты будут после его появления.

## Ревью не-автором, живой прогон и сдача (та же сессия, позже)

- **Независимое ревью кода** (правило «проверяет не тот, кто писал»):
  шесть агентов-ревьюеров по разным углам (построчный, трассировка стыков,
  сверка с макетом, reuse/simplification, efficiency/altitude, конвенции).
  10 находок принято и исправлено (`bceb97e`): гонка `refreshPayments`
  закрыта порядковым номером; мерчант фиксируется на старте операции,
  переключатель заморожен на inFlight; раскрытие description — по факту
  обрезки line-clamp; сетевые записи различают create/cancel и показывают
  причину браузера; таймаут fetch 15 с; `parseAmountInput` без искажений
  Number(); группа гонки красится по фактическим записям; конверт ошибки —
  одна функция поверх типов схемы; bodyOpen — локальное состояние записи;
  тест U2 чинён (свежий Response). Отклонено с обоснованием: окраска
  отмены-200 «цветом повтора» — так в принятом макете; CSS-микролитералы —
  перенос макета, оговорены комментарием в шапке app.css.
- **Решение проджекта по U4** (вторая итерация): показываем инвариант
  «платёж один», журнал печатает фактический исход (201+200 или 201+409),
  чип «201 + 200/409» как в макете, в группе — пояснение про тайминг.
  Отправка параллельная: оба fetch стартуют до первого await.
- **Живой прогон против psp-api** (бэкенд Рустема, CORS работает): 201
  «новый платёж» → 200 «тот же платёж» с тем же id/created_at и подсветкой;
  все пять сценариев; гонка на быстром бэкенде дала 201+200 — показано
  честно. Тесты 15/15, `npm run build` и `docker build` проходят.
- **Приёмочные скриншоты** — с продакшен-сборки в Docker (nginx, 8081)
  против живого API, на чистом мерчанте `demo-shop-b` (третьего перезапуска
  не понадобилось): пустые состояния; создание+повтор со списком, который
  не вырос (A1/A5); 409 `idempotency_key_reuse` (A2); description со
  `<script>` текстом (A10); гонка с пояснением; 375 без горизонтального
  скролла. Лежат в `frontend/screenshots/`, ссылки — в комментарии #12.
- Ложная тревога guard-scope: литерал `</script>` в аргументе браузерной
  команды прочитан как путь `/script` — обойдено записью JS в файл
  скретчпада и `browse eval`, хуки не трогались.
