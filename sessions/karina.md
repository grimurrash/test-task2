# Журнал координатора

Ведётся сессией-координатором по [регламенту](../docs/roles/karina.md).
Запись на каждое решение о выдаче задачи и на каждое закрытие: дословное
задание сэра, кому выдано и почему именно так, что вернулось в рапорте,
что помешало. Журнал уезжает в `main` одним pull request на смену вместе
с `REPORT.md`, а не по одному на задачу.

Форма записи:

```
## <дата> · #<номер тикета> · <Имя>-<номер тикета>

**Задание сэра (дословно):** …
**Тикет:** #N — <заголовок>
**Копия и ветка:** .worktrees/<slug>, <type>/<slug>
**Условие старта:** нет / <какое, кто следит>
**Рапорт:** <кратко: PR, CI, находки ревью, проблемы>
**Проверка факта:** gh pr view <N> → merged, gh pr checks → зелёный
**Закрыт:** <когда, с каким комментарием>
**Что помешало:** <отказы механизмов, задержки, дубли — или «ничего»>
```

### Три ложных отказа guard-scope переданы в #103

`/code` из подстроки `</code>` в grep-паттерне; `/var/log/psp.` из текста

### Разрешение: маркер allow-samples на журнал исполнителя

Основание: журнал, цитирующий обходы, по построению содержит то, что сканер
обязан находить, а дословность цитат — условие сдачи по регламенту. Убрать
цитаты значило бы потерять доказательство ради тишины механизма.

Условия: маркер в шапке с явно названным разменом; только на журналы, которые
действительно цитируют обходы. Цена вынесена в #150. Правило про журналы —
в регламент исполнителя, отдельной правкой.

### Проверка трёх экземпляров: как выглядит доказательство

`Рустем-103` проверил три ложных отказа, переданных из соседних сессий,
парным замером — `main` слева, ветка справа, один и тот же ввод. Не «стало
лучше», а две колонки на одной команде.

- **Экземпляр 1** (`/code` из `</code>`): `deny → allow`. Закрыт, вместе
  со второй формой того же класса.
- **Экземпляр 2** (`/var/log/psp.` из текста примера): отказ **остался** —
  цель записи и правда была вне репозитория, — но теперь называет настоящую
  причину. Автор экземпляра был прав дважды: и что отказ по существу верен,
  и что объяснение скрывало настоящую причину.
- **Экземпляр 3** (`//` из URL): **не воспроизвёлся**, в том числе на `main`.
  Запрошена дословная запись из `guard.jsonl` копии автора. В чужой журнал
  не полезла сама: правило про чужие копии одинаково для всех, включая
  координатора.

**Что забрать в регламент** — формулировка исполнителя, точнее моей:

> Утверждение «закрыто» на непроверенном экземпляре есть ровно то,
> за что эта задача заведена.

Он мог записать класс в закрытые по соседней форме, которая воспроизводится,
и никто бы не проверил. Вместо этого попросил дословную команду.

**Класс отказа, который стоит назвать отдельно** (экземпляр 2): механизм
