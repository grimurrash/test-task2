# Журнал координатора

Ведётся сессией-координатором по [регламенту](../docs/roles/karina.md).
Запись на каждое решение о выдаче задачи и на каждое закрытие: дословное
задание сэра, кому выдано и почему именно так, что вернулось в рапорте,
что помешало. Журнал уезжает в `main` одним pull request на смену вместе
с `REPORT.md`, а не по одному на задачу.

Форма записи:

```
## <дата> · #<номер тикета> · <Имя исполнителя>

**Задание сэра (дословно):** …
**Тикет:** #N — <заголовок>
**Копия и ветка:** .worktrees/<slug>, <type>/<slug>
**Условие старта:** нет / <какое, кто следит>
**Рапорт:** <кратко: PR, CI, находки ревью, проблемы>
**Проверка факта:** gh pr view <N> → merged, gh pr checks → зелёный
**Закрыт:** <когда, с каким комментарием>
**Что помешало:** <отказы механизмов, задержки, дубли — или «ничего»>
```
