# ДЗ №2 · агентная обвязка

Репозиторий домашнего задания №2 курса по ИИ-агентам. На этом этапе здесь стоит
окружение: механизмы вместо правил, повторяемый workflow и CI. Тема самой работы
выбирается отдельно — до неё в репозитории только каркас.

## Что уже есть

| | Что | Где |
|---|---|---|
| 1 | Восемь хуков: секреты, git, границы репозитория, недоверенный текст, гейт качества | `.claude/hooks/`, описание — [docs/HOOKS.md](docs/HOOKS.md) |
| 2 | Workflow `/feature`: план → ревью тремя агентами → реализация → ревью результата → MR → CI | `.claude/workflows/feature.js`, описание — [docs/WORKFLOW.md](docs/WORKFLOW.md) |
| 3 | CI: поиск секретов, поиск скрытых инструкций, проверка самих хуков | `.github/workflows/ci.yml` |

## Как проверить, что обвязка жива

```bash
python3 scripts/test_hooks.py        # 27 проверок хуков
python3 scripts/ci/scan_secrets.py   # секреты в отслеживаемых файлах
python3 scripts/scan_untrusted.py .  # скрытые инструкции в текстах
```

Все три запускаются в CI на каждый push и pull request.

## Как этим пользоваться

Хуки подхватываются, когда сессия агента открыта **в этой папке**. Проверить, что
они видны, просто: в начале сессии печатается приоритет инструкций и список
активных механизмов. Если этого блока нет — сессия открыта не там.

Задача целиком:

```
/feature <описание задачи>
```

## Стек

Не выбран. Файл `.ci-stack` содержит `none`, шаги `scripts/ci/{test,lint,analyse}.sh`
честно сообщают, что пропущены. Когда стек определится — команды вписываются туда,
а имя стека в `.ci-stack`; после этого пропуск шага станет ошибкой сборки.

## Структура

```
.claude/
  hooks/       восемь хуков и общая библиотека
  workflows/   feature.js — процедура на всю задачу
  commands/    /feature
  settings.json
scripts/
  test_hooks.py      проверка хуков реальным запуском
  scan_untrusted.py  поиск скрытых инструкций (используется хуком и CI)
  ci/                шаги сборки
docs/
  HOOKS.md     что чем защищено и где остаются дыры
  WORKFLOW.md  ступени процедуры
  plans/       планы задач, по файлу на задачу
```
