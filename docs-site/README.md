# Страница документации

Справочник API, собранный **из контракта** `openapi/openapi.yaml`, плюс
страница сценариев `curl`. Своего текста про поведение сервиса здесь нет:
раздел «Идемпотентность», таблица тестовых сумм и перечень кодов ошибок
живут в контракте и рендерятся из него. Контракт изменился — страница
пересобирается, расходиться им нечем.

Инструмент — [Scalar](https://github.com/scalar/scalar), сборка статическая:
в рантайме работает только nginx.

## Сборка

Из этого каталога:

```bash
npm ci
npm run build
```

Результат — в `dist/`: `index.html` (справочник), `scenarios.html` (сценарии
`curl`), копия контракта `openapi.yaml`, бандл Scalar и стили. Сборка печатает,
сколько операций и кодов ошибок нашла в контракте.

Посмотреть локально, без Docker:

```bash
npm run serve
```

Откроется `http://localhost:8082`. Порт переопределяется переменной `PORT`,
путь к контракту — переменной `SPEC`.

## Образ

Контекст сборки — **корень репозитория**, а не `docs-site/`: странице нужен
`openapi/openapi.yaml`, а копия контракта внутри `docs-site/` разошлась бы
с оригиналом на первой же правке.

```bash
docker build -f docs-site/Dockerfile -t psp-docs .
docker run --rm -p 8082:8082 psp-docs
```

Образ многоступенчатый (R3): Node собирает статику, в рантайм-слой едут только
`nginx` и `dist/` — ни `node_modules`, ни исходников сборки там нет.

В `compose.yaml` (задача #14) сервис объявляется с тем же контекстом:

```yaml
docs:
  build:
    context: .
    dockerfile: docs-site/Dockerfile
  ports:
    - "8082:8082"
```

## Сборка падает, если контракт неполон

`build.mjs` перед генерацией проверяет контракт и **прерывает сборку**, если:

- в нём нет ни одной операции или у операции нет `operationId`;
- код из перечня `ErrorCode` нигде, кроме самого перечня, не объяснён —
  иначе интегратор увидел бы имя кода без условия, при котором он приходит;
- нет `info.description` — то есть разделов «Идемпотентность», «Тестовые
  суммы» и «Формат ошибок», которые страница берёт оттуда.

Это и есть механизм требования «страница содержит все эндпоинты и все коды
ошибок»: не глазами при сдаче, а проверкой при каждой сборке.

## Что выключено и почему

Проверяющему обещан только Docker — **ни одного обращения в интернет** страница
делать не должна. Поэтому в конфигурации Scalar выключены:

| Что | Как | Почему |
|---|---|---|
| Шрифты с CDN Scalar | `withDefaultFonts: false` | без сети шрифты не приедут; берём системные, они заданы в `src/theme.css` |
| Панель разработчика (Deploy, Share) | `showDeveloperTools: 'never'` | ведёт на облако Scalar |
| Телеметрия | `telemetry: false` | страница учебного проекта никуда не отчитывается |
| Интеграция MCP | `mcp.disabled: true` | требует внешнего сервиса |
| Подсказки поиска из облака | `externalUrls.apiBaseUrl: ''` | запрос уходил на `api.scalar.com`; теперь он остаётся на своём хосте, а nginx отвечает на него пустым `204` |
| Кнопка «Open API Client» | `hideClientButton: true` | уводила в облачный клиент Scalar, передавая ему адрес `localhost`, до которого он не достучится |

Кнопка «Test Request» у каждой операции осталась: она шлёт запрос из браузера
читателя на `http://localhost:8080`, то есть работает ровно там же, где `curl`.

Поиск по документу при этом **работает офлайн** — он локальный.

Кнопка «Спросить AI» в сайдбаре остаётся видимой и офлайн ничего не находит:
отдельного флага, который её скрывает, в Scalar 1.66 нет, а прятать её по
внутренним классам вида `data-v-2e948397` — значит завести поломку, которая
всплывёт при первом же обновлении пакета. Оставлена сознательно.

## Токены оформления

Цвет и шрифты берутся из общего файла макета `design/tokens.css` (задача #10) —
того же, что использует песочница: две страницы проверяющий открывает подряд,
и они обязаны читаться как одна система.

Сборка подхватывает файл сама, если он есть в репозитории, и печатает, что
именно взяла. Файла нет — страница собирается на нейтральном дефолте и
остаётся читаемой; путь переопределяется переменной `TOKENS`.

`src/theme.css` — переходник: `--page-*` для обвязки страницы, `--scalar-*`
для справочника, значения — через `var(--токен, дефолт)`. Своих цветов он не
заводит. Из макета берутся **только цвет и типографика**: сетку, компоненты
и состояния справочника Scalar рисует сам.

Шрифт `Inter` из токенов не подгружается файлом — без сети его неоткуда взять,
и стек молча деградирует в системный. Это заложено в самих токенах.

## Версии

`@scalar/api-reference` закреплён точной версией (без `^`) плюс
`package-lock.json`: «страница пересобирается из контракта» обязано означать
один и тот же результат сегодня и через месяц, а не «собирается тем, что
сейчас в реестре».

```bash
npm run build                                    # сборка проходит, счётчики совпадают с контрактом

```
